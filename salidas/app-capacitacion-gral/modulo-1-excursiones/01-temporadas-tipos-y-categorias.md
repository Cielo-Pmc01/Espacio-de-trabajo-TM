# 01 - Temporadas, Tipos y Categorias

## Objetivo

Identificar rapidamente:

- Temporada de cada excursion (todo el ano / verano / invierno).
- Tipo (terrestres / lacustres / aventura).
- Categoria operativa (propias vs proveedor externo) para saber como consultar disponibilidad.

## Contenido

- Temporadas: Todo el ano, Verano, Invierno.
- Tipos de excursion: Terrestres, Lacustres, Aventura.
- Mapeo general: usar los catalogos vigentes.

- `contexto/catalog_invierno.md`
